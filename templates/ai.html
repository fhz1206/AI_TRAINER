📝 什么是Token？

大模型无法直接理解文字，需要先将文本拆分成一个个 Token（词元）。Token 可以是单词、子词(subword)甚至单个字符。

Tokenization：将句子拆分为模型可处理的 Token 序列

🔢 词嵌入 (Embedding)

每个 Token 被转换为一个高维向量，捕捉语义信息。语义相近的词在向量空间中距离更近。

例子："猫" 和 "狗" 的向量距离很近，而 "猫" 和 "汽车" 的距离较远。

🎯 注意力机制入门

自注意力让模型在处理一个 Token 时，能够"关注"输入序列中的其他所有 Token，从而理解上下文关系。

  • Q (Query)：当前 Token 在找什么
  • K (Key)：其他 Token 能提供什么
  • V (Value)：其他 Token 的实际内容

📉 损失率与困惑度

损失率（Loss）衡量模型预测与真实结果的差距，越小表示模型拟合越好。困惑度（Perplexity，PPL）是损失率的指数形式，反映模型对下一个词的"不确定程度"。

  • Loss = 0.0 → 完美预测，PPL = 1.0（完全确定）
  • Loss = 2.3 → 随机猜测，PPL = 词表大小
  • Loss = 5.0 → 几乎无效，PPL 极高

🎯 人工智能核心基础：梯度与优化

什么是梯度？

梯度是机器学习中最核心的概念之一，你可以把它理解为「函数增长最快的方向的向导」：

  • 在模型训练中，我们需要最小化「损失函数」（衡量模型预测和真实结果的差距）
  • 梯度是损失函数对每个参数的偏导数组成的向量，指向函数值上升最快的方向
  • 梯度下降算法的核心逻辑：往梯度的反方向更新参数，就能一步步走到损失函数的最小值点，让模型预测越来越准
