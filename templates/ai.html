📝 什么是Token？

大模型无法直接理解文字，需要先将文本拆分成一个个 Token（词元）。Token 可以是单词、子词(subword)甚至单个字符。

Tokenization：将句子拆分为模型可处理的 Token 序列

🔢 词嵌入 (Embedding)

每个 Token 被转换为一个高维向量，捕捉语义信息。语义相近的词在向量空间中距离更近。

例子："猫" 和 "狗" 的向量距离很近，而 "猫" 和 "汽车" 的距离较远。

🎯 注意力机制入门

自注意力让模型在处理一个 Token 时，能够"关注"输入序列中的其他所有 Token，从而理解上下文关系。

  • Q (Query)：当前 Token 在找什么
  • K (Key)：其他 Token 能提供什么
  • V (Value)：其他 Token 的实际内容

📉 损失率与困惑度

损失率（Loss）衡量模型预测与真实结果的差距，越小表示模型拟合越好。困惑度（Perplexity，PPL）是损失率的指数形式，反映模型对下一个词的"不确定程度"。

  • Loss = 0.0 → 完美预测，PPL = 1.0（完全确定）
  • Loss = 2.3 → 随机猜测，PPL = 词表大小
  • Loss = 5.0 → 几乎无效，PPL 极高

🎯 人工智能核心基础：梯度与优化

什么是梯度？

梯度是机器学习中最核心的概念之一，你可以把它理解为「函数增长最快的方向的向导」：

  • 在模型训练中，我们需要最小化「损失函数」（衡量模型预测和真实结果的差距）
  • 梯度是损失函数对每个参数的偏导数组成的向量，指向函数值上升最快的方向
  • 梯度下降算法的核心逻辑：往梯度的反方向更新参数，就能一步步走到损失函数的最小值点，让模型预测越来越准

🌐 AI、机器学习与深度学习的关系

三者是逐层包含的关系，不是同义词：

  • 人工智能（AI）：最大的概念——让机器表现出"智能"行为的全部技术总称，包括规则系统、搜索算法、专家系统等
  • 机器学习（ML）：AI 的子集——不再手写规则，而是让程序从数据中自动学习规律。典型算法：线性回归、决策树、SVM
  • 深度学习（DL）：ML 的子集——用多层神经网络自动提取特征。本平台的 CNN 与 Transformer 都属于 DL

💡 判断标准：需要人工设计特征（提取边缘、统计词频）的是传统 ML；原始数据直接进网络、特征由模型自己学的是 DL。

🕸️ 神经网络基础：从神经元到网络

神经元（Neuron）是神经网络的最小单元，工作方式模仿生物神经元：

  • 加权求和：z = w₁x₁ + w₂x₂ + … + b（w 是权重 weight，b 是偏置 bias）
  • 激活函数：对求和结果做非线性变换（下一节详解），没有它再深的网络也只能表达直线关系
  • 层级结构：输入层接收数据 → 隐藏层逐层提取特征 → 输出层给出预测结果
  • "深度"的含义：隐藏层的层数。层数越多，能表达的抽象特征越复杂（边缘 → 纹理 → 部件 → 整体）

💡 训练的本质就是不断调整所有 w 和 b 让预测误差变小——调整的依据正是「梯度」。

🔍 一个神经元在做什么？

x₁=2.0× w₁=0.5 ＋ x₂=1.0× w₂=−0.3 ＋ b=0.1 → z=1.8 → Sigmoid → a=0.86

求和结果 z=1.8 经 Sigmoid 压缩到 (0,1) 区间输出 0.86。真实网络中有成千上万个这样的神经元并行协作。

⚡ 激活函数：神经网络的"非线性开关"

如果只有加权求和，无论叠多少层，整个网络仍等价于一条直线。激活函数引入非线性，让网络能拟合任意复杂的曲线与模式。

  • Sigmoid：输出压缩到 (0,1)，适合二分类输出层；但深层易梯度消失，隐藏层已很少用
  • Tanh：输出 (−1,1)，零中心化比 Sigmoid 略好，同样有梯度消失问题
  • ReLU：负数归零、正数不变。计算极快、正区间不饱和，是 CNN 隐藏层的默认选择
  • GELU / SiLU：平滑版 ReLU，Transformer / 大模型的主流选择（本平台文本模型使用 GELU）
  • Softmax：把一组分数归一化为"和为 1 的概率分布"，专用于多分类输出层

🖼️ CNN 卷积网络：让机器"看懂"图片

卷积神经网络（CNN）是图像领域的核心架构，本平台的图像分类模型 SimpleResNet 就基于它。

  • 卷积核（Kernel）：一个小窗口（如 3×3）在图上滑动扫描，每个位置做点积——本质是在检测局部模式
  • 特征图（Feature Map）：一个卷积核扫完整张图的响应结果；不同卷积核检测不同模式（边缘/角点/纹理）
  • 池化（Pooling）：把 2×2 区域压成 1 个值（取最大/平均），缩小尺寸、保留显著特征、增强平移鲁棒性
  • 层级抽象：浅层看边缘 → 中层看纹理部件 → 深层看整体概念，这是 CNN 强大的根本原因
  • 参数共享：同一个卷积核在整张图上复用，参数量远小于全连接层，这是它能处理大图的关键

📊 数据集划分与过拟合

数据是模型的"教材"。规范的实验要求把数据分成互不相交的部分：

  • 训练集：模型学习规律的教材（通常占 70–80%）
  • 测试集：期末考试——模型从未见过的数据，衡量真实能力。拿测试集训练等于考试作弊
  • 过拟合（Overfitting）：把教材背得滚瓜烂熟、一考新题就崩——训练损失很低但测试表现差
  • 欠拟合（Underfitting）：教材都没学会，训练和测试都差
  • 常见对策：更多数据、数据增强（翻转/裁剪/加噪）、Dropout、正则化、早停（Early Stopping）

💡 本平台训练会整体使用你上传的数据集；评估模型请在「模型测试」页使用独立上传的测试数据，才能反映真实水平。

🎛️ 超参数与优化器：训练前的关键决策

参数（权重）由训练自动学得；超参数是训练开始前人工设定的配置，直接决定训练成败：

  • 学习率（Learning Rate）：每步参数更新的幅度。太大震荡发散，太小收敛缓慢——最重要的超参数
  • 批大小（Batch Size）：每次更新用多少样本。大批稳定但吃显存，小批噪声大但有轻微正则效果
  • 轮数（Epochs）：完整过几遍训练集。过多易过拟合，建议配合早停
  • 优化器：决定"往哪走、走多快"。SGD 是基础款；AdamW（本平台默认）能自适应调整各参数步长并正确执行权重衰减，是大模型时代的主流选择

学习率典型现象下山类比

📏 评价指标：如何量化模型好坏

不同任务用不同的"打分尺"，只看一个指标可能得出错误结论：

  • 准确率（Accuracy）：预测对的比例。直观但怕类别失衡——99% 都是正常样本时，"全猜正常"也能拿 99%
  • 精确率（Precision）：模型说"是"里面真正对的比例——衡量误报多不多（垃圾邮件误拦正常邮件 = 精确率低）
  • 召回率（Recall）：真实"是"里面被找出来的比例——衡量漏报多不多（癌症筛查漏诊 = 召回率低，代价更高）
  • F1 分数：精确率与召回率的调和平均，两者需要平衡时看它
  • 困惑度（PPL）：文本生成任务专用（见上文「损失与困惑度」），越低说明语言建模越好

🎲 采样策略：大模型怎么"写出"下一个字

语言模型每步输出的是词表上的概率分布。从分布里挑下一个词的方法，决定了生成文本的风格：

  • 贪心搜索（Greedy）：永远选概率最高的词——稳定但呆板，容易重复
  • 温度采样（Temperature）：先按温度 T 缩放 logits 再采样。T→0 接近贪心；T>1 更随机更有创意；T 太高会语无伦次
  • Top-K：只在概率最高的 K 个候选里采样，截断长尾降低胡言乱语风险
  • Top-P（核采样）：动态版 Top-K——按概率从高到低累加，取累计恰好达到 P 的候选集，候选数量随分布自适应
