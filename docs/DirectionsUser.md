## 平台简介

本平台提供以下核心功能：

- **🖼️ CNN 图像分类**：上传图片分类数据集，训练 SimpleResNet 卷积神经网络
- **📝 Transformer 文本生成**：上传文本数据，训练 Decoder-only 生成式大模型
- **🧪 模型测试**：加载训练好的模型，上传测试数据，自定义测试代码进行验证
- **✋ 手部关键点检测**：上传手部照片，使用内置 MediaPipe 模型检测 21 个关键点
- **📖 AI 基础学习**：交互式可视化学习页面，理解分词、词嵌入、注意力机制等概念
- **👤 账号管理**：修改用户名、密码，查看行为记录

## 训练面板

训练面板是平台的核心功能，支持图片分类和文本生成两种模型的训练。

### 选择训练类型

页面顶部有两个标签页：

- **🖼️ 图片训练** — 训练 CNN 图像分类模型
- **📝 文字训练** — 训练 Transformer 文本生成模型

点击标签切换，对应的参数面板和上传区域会同步变化。

### 上传训练数据

#### 图片数据集上传

**要求：**
- 仅支持 `.zip` 格式，最大 500MB
- ZIP 内顶层需包含多个文件夹，每个文件夹对应一个类别
- 每个文件夹内放置该类别的图片文件（支持 JPG/PNG/BMP/GIF）

**示例结构：**
```
dataset.zip
├── 猫/          # 类别名称 = 文件夹名
│   ├── cat001.jpg
│   ├── cat002.jpg
│   └── ...
├── 狗/
│   ├── dog001.jpg
│   └── ...
└── 鸟/
    └── ...
```

**上传步骤：**
1. 点击上传区域或拖拽 ZIP 文件到上传区
2. 系统自动解析 ZIP 结构并显示类别预览
3. 确认预览无误后点击 **✅ 确认上传数据集**
4. 上传成功后，该数据集会自动出现在数据集列表中

#### 文本数据集上传

**要求：**
- 支持 `.txt` 单个文件或 `.zip` 压缩包
- 每个 txt 文件内容为一条训练样本

**上传步骤：**
1. 点击上传区域或拖拽文件到上传区
2. 系统自动上传并显示成功提示

### 配置模型参数

#### CNN 图片模型参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 图片尺寸 | 输入图片的像素大小 | 224 |
| 分类数量 | 预计的分类类别数 | 10 |
| 基础通道数 | 卷积层的基础通道数 | 64 |

> 注意：实际分类数量由数据集自动推断，此参数仅供参考。

#### Transformer 文字模型参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 词汇表大小 | 模型词汇表容量 | 1000 |
| 最大序列长度 | 输入文本的最大 Token 数 | 128 |
| d_model | 模型隐层维度 | 512 |
| 编码器层数 | Transformer 层数 | 6 |
| 注意力头数 | 多头注意力头数 | 8 |
| 前馈维度 | 前馈网络维度 | 2048 |
| Dropout | 随机丢弃率 | 0.1 |

**高级选项：**
- **🔀 启用 MoE** — 混合专家模型（当前已禁用）
- **🎯 启用 MLA** — 低秩注意力机制

### 选择数据集

1. 在"选择训练数据集"区域，系统会列出所有已上传的数据集
2. 点击选择要使用的数据集（选中状态会显示 ✅）
3. 系统会自动校验数据集类型是否与当前训练类型匹配

### 设置训练超参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 学习率 | 控制参数更新步长 | 0.0001 |
| 训练轮数 | 完整遍历数据集的次数 | 10 |
| 批次大小 | 每次迭代的样本数 | 32 |

### 启动训练

1. 确认已选择正确的数据集
2. 调整好模型参数和训练超参数
3. 点击 **🚀 开始训练** 按钮
4. 训练任务会在后台异步执行

### 查看训练状态

训练启动后，状态区域会显示实时进度：

- **进度条** — 显示训练完成百分比
- **Loss** — 当前损失值
- **准确率** — 当前准确率（仅图片训练显示）
- **状态信息** — 当前训练轮次、批次等详细信息

训练完成后，状态会变为 **✅ 已完成**，模型自动保存到列表中。

### 下载模型

1. 在"已保存的模型"区域找到要下载的模型
2. 点击 **⬇️ 下载** 按钮
3. 浏览器会自动下载 `.zip` 压缩包（内含模型权重 `*.safetensors`、元数据与训练词表）

## 模型测试

测试页面用于加载训练好的模型，上传测试数据，并运行自定义测试代码。

### 选择框架与模型

1. 在顶部下拉框中选择模型框架：
   - **CNN 图片模型** — 测试图片分类模型
   - **Transformer 文本模型** — 测试文本生成模型
   - **✋ 手部关键点检测** — 使用内置手部检测模型
2. 选择对应的模型文件（手部检测模式自动选择内置模型）
3. 点击 **🔄 刷新** 按钮刷新模型列表

### 上传测试数据

#### 图片测试数据
- 仅支持 `.zip` 格式，结构同训练数据集
- 上传后系统自动解压

#### 文本测试数据
- 文本生成测试无需上传数据集，直接输入 Prompt 即可测试
- 如需计算困惑度可自行修改代码加载本地数据

#### 手部检测图片
- 支持 JPG/PNG/BMP 等常见图片格式
- 上传单张清晰的手部照片（正面、背景简洁、手部无遮挡）

### 编辑测试代码

测试页面提供代码编辑器，支持：

- **行号显示** — 左侧显示行号，方便定位代码
- **语法高亮** — Python 语法高亮（Dracula 配色风格）
- **Tab 缩进** — 按 Tab 键自动缩进 4 个空格
- **代码模板** — 切换框架时自动加载对应的默认代码模板
- **恢复默认** — 点击 **↺ 恢复默认模板** 按钮可恢复初始代码

**代码模板说明：**

**CNN 图片测试模板：**
- 自动加载模型和测试数据集
- 逐样本输出识别结果
- 计算并输出准确率

**Transformer 文本测试模板：**
- 自动加载模型和词表
- 输入 Prompt 进行文本生成
- 输出生成结果和统计信息

**手部检测模板：**
- 自动加载内置 MediaPipe 模型
- 检测手部 21 个关键点
- 输出关键点坐标和可视化图像

### 运行测试与查看结果

1. 选择模型、上传测试数据、编辑测试代码
2. 点击 **▶️ 运行测试** 按钮
3. 测试结果会显示在右侧结果区域，包括：
   - 运行日志（stdout 输出）
   - 错误信息（如有）
   - 测试指标（准确率、Loss、困惑度等）
   - 手部检测结果（关键点坐标和可视化图）

### 手部关键点检测

手部检测模式下，测试结果会显示：

- **21 个关键点坐标表格** — 每个关键点的 ID、名称、X/Y 坐标、置信度
- **基础标注图** — 在原始图片上标注关键点位置
- **彩色骨架图** — 用不同颜色区分手指，绘制手部骨架连线

## AI 基础学习

学习页面提供交互式可视化演示，帮助理解 AI 核心概念：

### 分词与 Token

- 输入任意文本，查看 BPE 分词结果
- 每个 Token 以不同颜色显示，悬停可查看 Token ID
- 支持中文、英文、数字和符号的混合分词

### 词嵌入

- 在二维空间中展示词语的语义距离
- 悬停词点查看与其他词的相似度
- 点击词点查看关联连接线
- 输入新词添加到空间中
- 语义相近的词在空间中距离更近

### 注意力机制

- 点击句子中的词，查看它与其他词的注意力权重
- 柱状图高度表示注意力分配比例
- 下方显示 Q（Query）、K（Key）、V（Value）的计算过程说明

### 梯度下降

- 观察红色小球（模型参数）沿梯度反方向滚动到最低点
- 调整学习率滑块观察收敛速度
- 调整噪声滑块模拟随机扰动
- 按 **R 键** 快速重置动画
- 实时显示当前位置、梯度范数、学习率

### Transformer 架构

- 动画展示数据在 Transformer 中的流动过程
- 悬停在各模块上查看详细功能说明
- 输入 → 词嵌入 → 多层注意力 → 输出

### 损失率与困惑度

- 模拟训练损失曲线，直观展示 Loss 下降过程
- 调整学习率观察收敛效果
- 调整噪声模拟真实训练随机性
- 实时显示当前 Loss 和 PPL（= e^Loss）值
- Loss 每降低 1.0，PPL 缩小约 2.7 倍

## 常见问题

### Q: 训练时出现"梯度爆炸/nan/inf"怎么办？

A: 平台已内置 8 大数值稳定性保护机制。如果仍然出现，建议：
1. 降低学习率（文本训练建议 ≤ 3e-5）
2. 减小 batch_size
3. 增大 dropout（但不超过 0.1）
4. 检查数据集是否有异常内容

### Q: Transformer 模型测试时生成结果为空怎么办？

A: 确保训练数据目录下存在词表文件 `*_token2char.pth`。测试模板会自动从三个位置查找词表：
1. 模型 `_metadata.train_params.data_path` 推断路径
2. 模型同目录的 `checkpoints_*` 子目录
3. `uploads` 目录全局搜索

### Q: 如何判断数据集是否上传成功？

A: 上传成功后，页面上方会显示绿色成功提示，数据集会自动出现在"选择训练数据集"列表中。

### Q: 训练需要多长时间？

A: 训练时间取决于数据集大小、模型参数和硬件配置。图片训练通常几分钟到几小时，文本训练时间更长。

### Q: 支持多用户同时使用吗？

A: 支持。每个用户的训练任务在独立线程中执行，数据按 `user_id` 隔离。但受限于 GIL，同一时刻只有一个线程在执行 PyTorch 计算。

### Q: 有什么方法可以快速停止训练？

A: 关闭浏览器不会停止训练，训练任务会在后台继续执行。如需停止，可以重启服务器。
